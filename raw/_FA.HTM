Voici la liste des mots par ordre alphabétique. Cliquer sur une lettre.
La liste donne la fréquence de chaque mot, c'est-à-dire le nombre de fois où le mot apparaît dans le texte.
Chaque mot est lié à ses concordances. Voir les instructions sur les concordances.

Voir aussi les statistiques par lettre initiale.


Pour chercher un mot, par exemple "maison":
  • Cliquer sur la lettre initiale: "M"
  • Appuyer en même temps sur les touches Control et F;
  • Ecrire le mot à chercher: "maison"
  • Appuyer sur la touche "Chercher". Le nom de la touche peut varier suivant les programmes de navigation.
    L'ordinateur trouvera et mettra en évidence le mot cherché. Si le mot est absent, un message apparaîtra.
  • Cliquer sur le mot pour accéder à ses concordances.
